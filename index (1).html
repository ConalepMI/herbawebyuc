Hopewell
Transparent Charity & Donation HTML Template

Thank you for choosing Hopewell — a complete, thoughtfully designed HTML template built for charity organizations, non‑profits, fundraising platforms, and community foundations. Rooted in the belief that generosity works best when it's traceable, Hopewell blends a warm amber-and-deep-navy palette with approachable typography, soft blobs, glowing gradients, and a preloader that sets a tone of hope and trust.

Hopewell is a single‑page, multi‑section template with 12 distinct content zones: a hero with floating stat cards, animated impact counters, an about collage, six active donation campaigns with progress bars, a why‑choose‑us grid, a three‑step how‑it‑works flow, volunteer profiles with hover overlays, a testimonial carousel, a full‑width CTA banner, a contact section with form and map placeholder, and a comprehensive footer with newsletter signup. A sticky mobile donate bar, a scroll‑to‑top button with SVG progress ring, and a video story modal round out the interactive experience.

Version: 1.0  |  Last Updated: August 2026

🚀 Installation

Hopewell uses plain HTML, Bootstrap 5, the AOS animation library, Bootstrap Icons, and vanilla JavaScript. No build tools, npm, or package managers are required — just unzip and open.

1. Download and unzip the purchased package. 2. Open the project folder. 3. Double‑click index.html to preview in your browser. 4. For editing, we recommend VS Code with the Live Server extension.
Quick Start: Just open index.html and start editing. All dependencies (Bootstrap, Bootstrap Icons, AOS, Google Fonts) load from CDNs — no command line needed. The local assets folder contains minified Bootstrap files, the custom stylesheet, and the JavaScript file.

🎨 Colors & Typography

Change Brand Colors

Open assets/style.css and edit the :root block. Every component references these CSS custom properties, so changing them updates the entire site instantly:

:root { --clr-primary: #F59E0B; /* warm amber — buttons, links, accents */ --clr-primary-dark: #D97706; /* deeper amber for hover states */ --clr-secondary: #0F172A; /* deep navy — footer, dark backgrounds */ --clr-bg: #FDFBF7; /* warm cream — section backgrounds */ --clr-white: #FFFFFF; --clr-text: #1C1917; /* near‑black for body text */ --clr-text-muted: #6B7280; /* muted gray for secondary text */ --clr-border: #E5E7EB; /* light border color */ --clr-accent-glow: rgba(245, 158, 11, 0.25); /* amber glow for hero */ --font-display: 'Poppins', sans-serif; /* headings */ --font-body: 'Nunito Sans', sans-serif; /* body text */ --radius-card: 16px; --radius-btn: 50px; }

Change any value and every button, link, card, glow, and hover state updates automatically — no need to hunt through the stylesheet.

Typography

Hopewell uses Poppins (a friendly, geometric sans‑serif) for all display headlines and Nunito Sans (a clean, rounded sans‑serif) for body text. Both are loaded from Google Fonts in the <head>. To change them:

  1. Update the Google Fonts <link> in index.html with your chosen fonts
  2. Edit the --font-display and --font-body variables in style.css
  3. Update the font-family fallback stacks as needed
Font weights used: Poppins 400, 500, 600, 700, 800 — Nunito Sans 400, 500, 600, 700. Make sure your replacement fonts include similar weight ranges for consistent visual hierarchy.

📬 Forms & Interactions

The contact form (#contactForm), newsletter input, and all donation buttons use event.preventDefault() for demonstration. You can connect them to any backend:

  • Formspree — add your endpoint to the form's action attribute
  • Netlify Forms — add the netlify attribute to the <form> tag
  • PHP Mail — point the form to your mailer.php script
  • Zapier / Make — webhook integration via fetch()

Your message has been sent.'; statusEl.className = 'text-success mt-2'; this.reset(); });

Other interactions — preloader fade‑out, counter animations, campaign progress bar fills, scroll‑to‑top button with SVG ring progress, mobile menu toggle, AOS initialization, and the story modal — are all fully functional out of the box and require no API keys or configuration.

Interaction Summary

  • Preloader: Hides after window load with a fade‑out transition
  • Counters: Animate on scroll using IntersectionObserver — increment from 0 to target
  • Progress Bars: Read data-progress attributes and animate width on load
  • Scroll‑to‑Top: Appears after 300px scroll; SVG ring tracks scroll percentage; smooth scrolls to top on click
  • Mobile Donate Bar: Shown/hidden based on viewport width and scroll position
  • AOS: Initialized with default easing and once‑per‑visit settings
  • Navbar: Bootstrap collapse with hamburger toggler on mobile
  • Testimonial Carousel: Bootstrap carousel with auto‑cycling and manual indicators

❓ FAQ & Support

How do I change the donation amounts?

Open index.html and locate each campaign card inside the #causes section. Update the .raised and .goal spans, and adjust the data-progress attribute on the progress fill element to reflect the new percentage.

How do I add a new campaign?

Copy an existing .cause-card block inside the .row.g-4 container in the Causes section. Update the image src, category tag, title, description, progress bar data-progress, and raised/goal amounts. The grid uses Bootstrap's col-md-6 col-lg-4 classes, so it automatically handles 2‑per‑row on tablets and 3‑per‑row on desktops.

How do I connect the contact form to receive emails?

The simplest approach is Formspree: sign up at formspree.io, create a form, and paste your unique endpoint URL into the contact form's action attribute. For Netlify, add netlify to the <form> tag. The JavaScript handler in script.js is already set up to work with either approach.

Can I make this a multi‑page site instead of single‑page?

Yes. Each section (#about, #causes, #contact, etc.) can be extracted into its own HTML file. Copy the shared navbar and footer into each page, update the navigation links to point to the new files instead of anchor hashes, and you'll have a traditional multi‑page site.

How do I change the favicon?

Replace assets/hand-heart.png with your own icon file. For best results, use a 64×64px PNG. If you prefer a different filename, update the <link rel="icon"> tag in the <head> of index.html.
